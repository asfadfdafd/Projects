# Запуск Remotion-проекта

## Быстрый старт

```bash
# 1. Перейдите в папку проекта
cd remotion-audit-demo

# 2. Установите зависимости
npm install

# 3. Запустите превью (откроется в браузере)
npm start

# 4. Рендер финального MP4
npm run build
```

Готовый файл появится в папке `out/demo.mp4`.

## Как кастомизировать

### Изменить длительность сцен
Откройте `src/theme.ts` → `VIDEO.scenes` → правьте значения в секундах.

### Изменить сообщения в чате
Каждая сцена содержит массив `messages: MessageDef[]`.
- `text` — текст сообщения
- `isBot: true` — сообщение бота (левый), `false` — клиента (правый)
- `startFrame` — кадр появления (относительно начала сцены)
- `time` — время в шапке пузыря

### Изменить цвета
Все цвета в `src/theme.ts` → объект `theme`.

### Добавить музыку
```tsx
// В AuditDemo.tsx добавьте:
import {Audio, staticFile} from 'remotion';
// Положите файл в public/background.mp3
<Audio src={staticFile('background.mp3')} volume={0.3} />
```

### Изменить разрешение
`src/theme.ts` → `VIDEO.width` и `VIDEO.height`.
Для вертикального (1080×1920): поменяйте значения и
обновите SplitLayout на вертикальный стек.
