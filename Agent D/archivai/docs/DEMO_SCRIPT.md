# Сценарий показа клиенту (~15–20 мин)

Цель: показать всё, что Agent D показывал, всё, что он только ОБЕЩАЛ (агентный слой,
семантический поиск, профили/SSO-готовность, комплаенс, коннекторы, IoT), и два
козыря, которых у него нет вовсе: **«Ask ArchivAI»** (чат с цитатами) и **агент,
который реально действует**. Всё — на открытых моделях, полностью on-prem.

---

## 0. Подготовка (за час до показа)

```bash
cd archivai
# 1. Реальные модели: в .env AI_STUB=0, Ollama запущен (ollama list)
docker compose up -d --build ai-service && make web-rebuild && docker compose up -d
# 2. Настоящий вход: в .env AUTH_OPTIONAL=0
docker compose up -d --force-recreate web
# 3. Чистая витрина (smoke-мусор удаляется, аудит остаётся):
make demo-clean
# 4. Наполнение: 10–15 реальных сканов в бакет import (MinIO: localhost:9001,
#    archivai / change_me_minio) — НЕ забирать заранее, это часть показа.
#    1–2 документа залить заранее через Upload и дать обработаться (для поиска/чата).
# 5. Датчик (отдельный терминал, оставить работать):
make sensor-demo
# 6. Прогнать этот сценарий один раз самому. Держать qwen «тёплым» (любая фраза агенту).
```

Контрольные точки готовности: /login встречает формой · на /dashboard живёт
Storage Environment · в архиве есть 1–2 обработанных документа.

---

## 1. Вход и комплаенс-рамка (1 мин)

Войти `demo@archivai.local / archivai-demo`. Реплика: «каждый вход, поиск и просмотр
документа фиксируется с IP — это увидим в конце на экране комплаенса».

## 2. Bulk-заливка из хранилища клиента (2 мин)

Upload → **⇩ Pull from storage** → «Найдено N, отправлено в обработку N».
Documents: документы появляются со статусом processing и добиваются по мере OCR.
Реплика: «системе нужны только ваше файловое хранилище и база — коннектор
забирает пачками сам, каждые 5 минут; выгрузка обратно в вашу учётную систему —
структурированным JSON с ретраями (outbox), покажу в n8n при вопросе».

## 3. Документ и человек-в-контуре (3 мин)

Открыть обработанный документ: скан с зумом · тип/дата/язык · отправитель/получатель
с ролями · AI-резюме · сущности по 5 категориям. Поправить одну сущность инлайн →
**Mark as Verified**. Реплика: «verified-документы защищены — даже массовая
переобработка агентом их не тронет».

## 4. Семантический поиск (2 мин)

Search: запрос смыслом, не словами (например «письма о юбилейных мероприятиях»).
Показать чипы недавних запросов (персональная история — тоже в комплаенс-журнале).

## 5. ⭐ Ask ArchivAI (2 мин) — «у Agent D этого нет»

Chat: «Кто и кому писал об этом документе?» → ответ с цитатами **[1]**, клик по
цитате открывает первоисточник. Реплика: «ответы только из вашего архива, без
галлюцинаций; не нашёл — честно скажет».

## 6. ⭐⭐ Агент (5 мин) — кульминация

На /agent, последовательно:
1. «Сделай поиск более семантическим» → diff-чип 0.7→0.9, справа конфиг обновился.
2. «Добавь виджет: динамика приказов по годам» → на Dashboard появилась карточка
   с меткой agent.
3. **Главная**: «Добавь тип документа „протокол“ и переклассифицируй документы» →
   зелёный чип таксономии + `↻ на переобработку: N док.` → через минуту-две в
   архиве типы реально меняются.
Реплика: «LLM не имеет доступа к базе — он лишь предлагает действия, Postgres
валидирует каждое поле; вот красный чип, если модель ошибётся» (при желании
показать: «сделай вес поиска 5» → отказ валидатора).

## 7. Сущности и граф (1 мин)

Entities: дубликаты слиты (алиасы сохранены), CSV-экспорт, граф связей
человек↔организация↔место, клик → документы.

## 8. Dashboard + IoT (1 мин)

Dashboard: единые цифры из одного источника + **Storage Environment** — живые
температура/влажность хранилища (зелёные в норме 16–20°C / 40–55%). Реплика:
«любые ваши датчики/системы шлют POST на один вебхук».

## 9. Финал — комплаенс (1 мин)

/usage (виден только админу): поиски по дням, топ-запросы, самые используемые
документы, активные сессии, журнал входов с IP (включая неудачные).

## Козыри против Agent D (если спросят «чем лучше»)

- Чат-ассистент с цитатами — у них нет вовсе; агентный слой — у них обещание, у нас
  работает вживую (конфиг + операции + кастомные виджеты).
- Настоящая дедупликация сущностей с алиасами; consistent-цифры дашборда (у них на
  демо 67 против 108 в разных местах); provenance + confidence на каждом извлечении.
- Полностью открытые модели, on-prem, ничего не покидает контур; модель
  масштабируется заменой одной строки в .env (3B → 7B/72B на GPU-хосте).
- Каждый этап — видимый n8n-workflow: расширяемо без переписывания продукта.

## Если что-то пойдёт не так

- Агент ответил словами без действий → UI честно покажет «настройки не менялись»;
  повторить фразу проще/по одной интенции. Это тоже можно продать: «система никогда
  не делает того, о чём модель лишь говорит».
- Пайплайн долго обрабатывает (CPU) → показать статус processing как фичу
  (асинхронность), вернуться к документу позже.
- Полный сбой сервиса → `docker compose ps`, `docker compose up -d`; Ollama:
  `ollama list`.
