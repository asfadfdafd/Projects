# ArchivAI — демонстрационный ролик

Проект Remotion для ролика о возможностях ArchivAI. Русский язык, фирменный стиль
продукта, 1920×1080 @ 30 fps, **2 минуты 27 секунд**, 12 сцен.

Смонтирован из настоящих записей экрана и снимков рабочей системы — то есть
показывает продукт, а не рисованные макеты.

Тексты написаны для сотрудника архива: «распознавание» вместо OCR, «поиск по
смыслу» вместо семантического, «работает на вашем сервере» вместо on-premise.
Технические названия оставлены в одном месте — мелкой строкой в сцене «Как это
работает», для технической службы.

## Как отрендерить финальную версию

Нужен Node.js 18+ (в проекте `archivai/web` он уже используется).

```bash
cd "Agent D/video"
npm install          # первый раз: подтянет Remotion и headless Chrome (~5 мин)
npm run render       # → out/archivai-demo.mp4
```

Посмотреть и подвигать сцены вживую, с таймлайном:

```bash
npm run studio       # откроется Remotion Studio в браузере
```

Другие команды:

```bash
npm run render:hq        # тот же ролик, но с меньшим сжатием
npm run render:teaser    # короткая версия ~1 мин (интро → проблема → поиск → чат → агент → финал)
npm run cover            # кадр-обложка → out/cover.png
npm run typecheck        # проверка типов
```

## Музыка

Ролик рассчитан на фоновую музыку без закадрового голоса — весь смысл несут титры.

1. Положите трек в `public/audio/`, например `public/audio/music.mp3`.
2. В `src/theme.ts` замените:

```ts
export const MUSIC_FILE = null as string | null;
// на
export const MUSIC_FILE = 'audio/music.mp3' as string | null;
```

Громкость и плавное затухание в конце уже настроены (`MUSIC_VOLUME`, по умолчанию 0.22).
Хронометраж — ровно 147 с, под него удобно подбирать трек.

Что подойдёт по характеру: спокойный корпоративный минимал, без вокала и без
резких акцентов — ролик про архивы и доверие к данным, а не про запуск стартапа.

## Как что-то поменять

**Длительность сцены.** `src/timeline.ts` → `SCENE_SECONDS`. Общая длина
пересчитается сама, ничего больше править не нужно.

**Убрать или переставить сцену.** Там же, массив `ORDER`. Короткая версия — `TEASER_ORDER`.

**Тексты.** Каждая сцена — отдельный файл в `src/scenes/`, тексты лежат прямо в разметке.

**Цвета и шрифт.** `src/theme.ts`. Палитра снята пипеткой со скриншотов продукта:
тёмно-синий `#111B31`, оранжевый `#E87B35`, фон `#F2F5F9`.

**Раскладки кадра.** `src/layout.ts` — три схемы: рамка слева / рамка справа /
большая рамка по центру.

⚠️ Если меняете длительность сцен с записями экрана (`upload`, `process`, `verify`,
`search`, `ask`, `control`), проверьте, что клипу хватает кадров — константы
вроде `CLIP_UPLOAD`, `TYPE_END`, `ASK_END` в начале файлов сцен. Скрипт
`preview/verify.py` проверяет это автоматически.

## Чего в ролике нет

**Сцена «Вопрос архиву» снята с монтажа.** В записи ответ ассистента построен на
скане с шумным распознаванием и в кадре читается плохо. Сама сцена собрана и
лежит готовой (`src/scenes/S08Ask.tsx`). Чтобы вернуть: запишите диалог на
документе с чистым текстом, замените `public/clips/07_ask.mp4` и
`08_answer.mp4`, добавьте `'ask'` в `ORDER` в `src/timeline.ts` после `'search'`.
Ролик станет 2:45.

Вместе с этой сценой из ролика ушло заметное преимущество — ответы со ссылкой
на документ, чего у Agent D нет. Стоит вернуть при первой возможности.

**Страницы «Настройка», «Сводка» и «Связи» показаны снимками экрана** — живой
съёмки этих разделов в материалах не было. Если запишете их в работе (особенно
настройку: как фраза словами превращается в изменённые настройки), клипы
вставляются вместо снимков без изменений в структуре.
